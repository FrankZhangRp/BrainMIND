Overview

This project evaluates the performance of large language models (LLMs) in automated brain MRI report analysis and diagnosis generation. The system processes unstructured MRI reports and generates structured diagnostic conclusions using state-of-the-art language models deployed via VLLM.

Key Findings

Best Performance

DeepSeek-R1 achieved the highest performance among 10 evaluated LLMs on 4,293 brain MRI reports.

97.6% Accuracy

Top-3 differential diagnosis prompting achieved 97.6% patient-level accuracy vs 87.1% for single diagnosis.

Improved Efficiency

LLM assistance reduced radiologist reading time from 61s to 53s while improving diagnostic accuracy.

15 Disease Categories

Comprehensive evaluation across 15 brain disease categories with 9,973 diagnostic labels.
